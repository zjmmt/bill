# 术语表

- 状态：已确认
- 所有者：项目维护者
- 最后核验：2026-07-19
- 事实来源：领域模型

| 术语 | 定义 |
| --- | --- |
| 数据来源（Source） | 产生证据的平台或渠道，如支付宝、微信支付、某银行、账单文件或手工录入。 |
| 采集方式（Capture Method） | 通知、文件导入、分享、手工等取得证据的方式；不等同于来源。 |
| 渠道（Channel） | 用户完成支付所经过的平台，如支付宝或微信支付；可能不持有实际资金。 |
| 资金账户（Funding Account） | 实际增加、减少或形成负债的账户，如银行卡、信用卡、支付宝余额。 |
| RawEvent | 不可变原始证据及其元数据。 |
| Draft | 从证据解析出的候选事件，尚未成为正式账务事实。 |
| Transaction | 经确认的经济事件。 |
| Entry | Transaction 对账户余额的单个影响；成组后必须满足平衡规则。 |
| TxRelation | 两份证据或交易之间的重复、资金来源、退款、转账配对等关系。 |
| 过账（Post） | 将确认后的 Transaction/Entries 原子地写入正式账本。 |
| 对账（Reconcile） | 用余额、外部 ID 和多份证据验证、关联或修正账本。 |
| 适配器（Adapter） | 把特定来源/格式转换成统一候选字段与诊断的边界组件。 |
| 一等数据源 | 在范围、架构与验收中独立存在，不能用另一个来源“未来再兼容”代替。 |
| 覆盖同级 | 每类来源都有可用路径与验收；不表示通知文案、导出格式或自动化程度完全相同。 |
| local-first | 核心数据与计算以设备本地为主，无网络仍可完成核心任务；同步若存在也是可选能力。 |
