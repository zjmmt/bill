# ADR-0003：不可变证据、草稿、平衡分录和显式关系

- 状态：已接受
- 所有者：项目维护者
- 最后核验：2026-07-19
- 事实来源：原报告的核心账务方案与多来源去重要求

## 背景

同一消费可能同时出现为支付平台通知、银行扣款、pending/posted 和后导入账单。若每条观测直接成为收支，会重复；若简单删除“重复行”，又会丢失资金来源和审计证据。

## 决定

系统分四层处理：

1. `RawEvent` 保存不可变外部证据。
2. `Draft` 保存带版本、置信度与用户修改的候选。
3. `Transaction + Entry` 表示经确认经济事件和对账户的平衡影响。
4. `TxRelation` 表示重复、pending/posted、资金来源、转账、退款、还款等关系。

解析、分类和关联可以重放；原始证据和用户审计不可静默覆盖。

## 结果

- 正面：可解释、可撤销、可对账，支持来源格式升级和用户修正。
- 代价：数据模型与 UI 比单表流水复杂，需要关系候选、审计、迁移和性质测试。
- 约束：所有正式分录满足金额/币种不变量；关系阈值必须按类型用样本校准。

## 被否决方案

- 通知到达即写一条正式收支。
- 只用单一 `externalTradeNo` 表示所有来源。
- 发现重复就删除其中一条原始记录。
