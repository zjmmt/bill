# ADR-0001：核心产品本地优先且不依赖自有服务端

- 状态：已接受
- 所有者：项目维护者
- 最后核验：2026-07-19
- 事实来源：项目目标

## 背景

财务数据高度敏感。项目的差异化价值来自离线可用、默认不上传和用户可迁移，而不是云端账户聚合。

## 决定

核心采集后的解析、账本、搜索、对账、备份和恢复均在 Android 设备本地完成。MVP 不建设项目方服务器，也不要求用户注册云账号。

未来任何网络价格更新、用户自控同步或远程诊断都是可选能力，必须单独记录数据类别、目的、第三方、加密和删除边界。

## 结果

- 正面：离线可用，数据主权清晰，降低服务器泄露面和运营成本。
- 代价：跨设备同步、银行直连和远程规则更新更难；设备丢失恢复依赖用户备份。
- 约束：核心发行构建不应因第三方 SDK 意外引入不必要网络权限；需持续检查 Manifest 和依赖。

## 被否决方案

- 默认上传所有账单到自有云：违背核心承诺。
- 仅做自托管 Web 服务：提高部署门槛，无法提供 Android 原生即时采集主体验。
