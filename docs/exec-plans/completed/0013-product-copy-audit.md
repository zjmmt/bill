# ExecPlan 0013：发布界面文案收口

- 状态：已完成
- 所有者：项目维护者
- 最后核验：2026-08-02
- 事实来源：三套 Android 字符串资源、Compose 发布界面、[UI 设计系统](../../design-docs/ui-design-system.md)、项目负责人当前反馈

## 目的与用户可见结果

全面检查发布版用户可见文本，移除工程进度、测试状态、内部实现术语和重复说明。界面只保留用户做决定所需的内容：当前结果、权限范围、不可逆影响、识别不确定性和下一步。

## 范围与非目标

包含：英文、简体中文、繁体中文资源；发布版 Compose 硬编码文本；通知类型名称；常驻页面说明；权限、删除、导入、OCR 和对账提示；文案规则与自动校验。

不包含：Debug 通知采样器的开发者诊断文本、改变账务语义、扩大权限、宣称未通过发布门的来源已稳定支持。

## 验证与验收

- 三种语言的资源键与格式占位符完全一致。
- 发布版不出现“实验性、解析器、模板、路线、回调、队列、进程、契约、样本验证、重放、资金腿、审计、不可变、证据”等内部术语。
- 发布 Compose 不包含未本地化的用户文案；Preview、测试夹具和 Debug-only 采样器除外。
- 常驻页面标题下不重复讲产品规则；高风险能力在用户操作前说明范围。
- `lint`、相关单元测试、Debug 构建、仓库结构/敏感边界检查及签名真机复验通过。

## 结果与复盘

三语言资源键与占位符校验通过；发布源码术语扫描没有命中禁用工程词；`:app:testDebugUnitTest :app:lintDebug` 通过（341 个任务）；架构边界、敏感边界、生成事实和仓库自测通过。固定签名的 arm64 v3 APK 已在 `S24U-HK` 以覆盖安装方式成功安装，包标志不含 `DEBUGGABLE`，冷启动 `TotalTime` 为 462 ms。

审查结束后，当前源码把既有的 Android 通知读取范围和微信共享通知频道说明提前到 route 开关之前；该位置调整不在已交付的 v3 APK 中。项目负责人明确决定不为这一处说明位置单独生成 v4，因此 v3 保持为本轮交付物，位置调整随下一次正式签名构建进入安装包。这项差异不改变权限范围、采集行为或账务语义。

本计划只收口发布界面文案，不宣称完整设备矩阵、真实生产通知 callback 或签名 Release 资源门已经完成。
